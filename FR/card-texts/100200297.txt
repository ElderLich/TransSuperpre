[name]
Pazou le Magicien Blindé

[desc]
(Cette carte est toujours traitée comme carte "Prophétie".)
Si cette carte est dans votre main ou Cimetière : vous pouvez cibler 1 monstre face recto que vous contrôlez ; équipez-lui cette carte comme Magie d'Équipement avec les effets suivants. Vous ne pouvez utiliser cet effet de "Pazou le Magicien Blindé" qu'une fois par tour.
● Le monstre équipé gagne 2100 ATK/DEF tant que vous avez max. 4000 LP.
● Lorsqu'une carte ou un effet activé par votre adversaire est résolu, si vous contrôlez une carte avec un effet qui nécessite un lancer de dé, vous pouvez annuler l'effet activé, puis bannissez cette carte.
