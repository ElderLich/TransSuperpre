[name]
Golem Immondices

[desc]
Si vous contrôlez un monstre avec 0 ATK ou DEF : vous pouvez Invoquer Spécialement cette carte depuis votre main.
Vous pouvez révéler 3 Monstres Xyz de Rangs différents dans votre Extra Deck, puis ciblez 1 autre carte sur le Terrain ; détruisez-la ainsi que cette carte.
Vous pouvez bannir cette carte depuis votre Cimetière ; détachez 1 Matériel d'un monstre que vous contrôlez, puis vous pouvez Invoquer Spécialement 1 monstre avec 0 ATK ou DEF depuis votre main ou Cimetière.
Vous ne pouvez utiliser chaque effet de "Golem Immondices" qu'une fois par tour.
